# Traceability

The maintained requirement-to-evidence verification matrices are in
[`verification.md`](verification.md). Normative requirements remain in
[`../requirements/SRS.md`](../requirements/SRS.md).

The matrices map every SRS requirement to maintained verification evidence at
the production boundaries: automated and hardware tests, user documentation,
and design review.
[Integration qualification](verification.md#integration-qualification)
describes the external qualification boundaries and remaining hardware limits.
A normative contract or a maintained test alone does not establish external
acceptance. Archived design-analysis references explain durable rationale and
are separate from current acceptance evidence.
