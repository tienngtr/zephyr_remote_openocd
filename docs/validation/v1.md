# V1 Validation Evidence

This record summarizes current V1 evidence without embedding local lab fixture
identities. Concrete boards, probes, serial devices, and remote paths remain in
ignored external fixture configuration.

## Native Linux

The maintained automated suites cover module discovery, setup and configuration,
runner registration and selection, recording-mode command construction, helper
protocol and staging safety, local process lifecycle, SSH transport, forwarding,
and cleanup. Real-hardware fixture suites cover flash, persistent debug/attach/
debugserver, RTT on capable targets, and direct semihosting on capable targets.
Capability-specific tests are independent; unsupported optional capabilities do
not suppress other operations.

The Git-free clean-install acceptance copies the distributed tree, uses an
isolated home, runs setup, verifies configuration preservation and permissions,
activates only the copied module through `EXTRA_ZEPHYR_MODULES`, and exercises
recording-mode runner registration without Git metadata.

## Deferred platform checks

PG-012 (WSL Linux OpenSSH) and PG-013 (Windows `ssh.exe` invoked from WSL 2)
remain explicitly deferred until a WSL 2 environment is available. They are the
only deferred V1 acceptance validations.

## Startup overhead

`startup-overhead-v1.json` records the release benchmark for
`REQ-NFUNC-PERF-001`. The procedure uses five warm-ups and 100 measured
iterations per applicable command, reports first observation, median, p95, and
worst values, and evaluates the paired remote-minus-built-in median against the
0.5-second target. The built-in `openocd --context` result is documented as a
conservative lower-bound proxy, not an equivalent command execution. SSH
authentication, network transfer, external network latency, remote OpenOCD
initialization, and hardware target initialization are excluded.

This benchmark is manual release evidence and is not a CI timing gate.
